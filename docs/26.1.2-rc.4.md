# 劫后余生 26.1.2 · 0.0.4-rc.4

本次仅更新 Minecraft 26.1.2 的 NeoForge 版本。验证环境为 NeoForge 26.1.2.109、Java 25。

## 猪灵装备

- 实体在波次位置执行原版/NeoForge 出生初始化，再应用波次配置；首波猪灵也会有武器。
- 副本普通猪灵作为成年战斗单位生成，空手时补金剑或弩；猪灵蛮兵恢复原版初始武器。
- 后期配置的装备直接放入对应装备槽，不再依赖可能拒绝物品的拾取 AI；同时纠正装备掉落开关。

## 副本怪物掉落

- 副本怪物死亡不产生物品、装备或经验球；通关奖励照常发放。
- 岩浆怪分裂后的小怪继承无掉落规则和所属副本；不再把附近自然生成的岩浆怪算入副本。
- 无掉落标记随实体保存，副本结束后仍保留；能够识别旧版战斗标记的存活怪物也会应用规则。
- 玩家死亡背包及自然生物的正常掉落保留。已经落在地上的旧物品不回收。

## 胜利音乐

- 以遗迹建筑包围盒中心为声源，48 格范围内随距离线性衰减，到范围外静音。
- 原双声道 Ogg 转为单声道以支持位置衰减，保留完整曲目时长约 4 分 30 秒。音量使用游戏的“唱片机／音符盒”分类。
- 发奖结束不停止歌曲；成功用钻石打火石重新激活时停止上一首胜利音乐，开始新挑战。
- 激活失败或仍在发奖时尝试激活，不会停止歌曲。
- 多人中有人离开不影响范围内其他人；最后一名玩家离开有效范围后，本次播放结束，回来不会续播。
- 若范围内始终有人，其他人中途进入时从本次歌曲的当前进度加入，不从头重播。歌曲播完、离开世界或服务器卸载该维度后清理播放。

## 安装与复现

用新 JAR 替换旧的 26.1.2 JAR；联机时客户端和服务器同步更新。基础副本玩法不需要 KubeJS。

在本工程目录、Java 25 下分开执行：

```powershell
.\gradlew.bat runData
.\gradlew.bat runGameTestServer build
.\gradlew.bat clientAudioCheck
.\gradlew.bat -PwithKubeJS runGameTestServer
```

可选 KubeJS 验证组合：KubeJS 26.1.2-8.0.6、Rhino 2101.2.8-build.91、Better Advanced Tooltips 2601.1.0-build.9。
