# 劫后余生 rc.24：进度条文字排版

- 难度名称（简单／普通／困难）居中显示在进度条上方。
- 难度文字使用与进度条相配的红、橙、金色，约 6 秒完成一次平滑渐变循环，不依赖帧率。
- 波次单独居中显示在进度条下方，例如「第 6/13 波」；英文为「Wave 6/13」。
- 上下文字之间预留完整进度条高度；同时出现多个进度条时，为后续进度条预留文字间距。
- 直接读取服务端标题的结构化难度、当前波与总波数，不按中文或英文字符串切分；原有存档与标题同步格式保持兼容。
- 本次为客户端 HUD 修改，保留 rc.23 的步行登场以及已有怪物、奖励、商人和城市功能。
