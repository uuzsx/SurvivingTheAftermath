# 劫后余生 rc.8 · 分支和模组信息

默认分支 main 对应 Minecraft 1.20.1 Forge。1.21.1、1.21.2、26.1.1、26.1.2、26.2、26.3 分别在同名 NeoForge 分支，根目录均可独立构建。

作者统一为 sxuuz，维护账号为 uuzsx。恢复原发布页 Logo 和简介，添加中文玩法说明，并在每个 JAR 中包含 MIT 许可与原有版权声明。原 Logo 转为 Minecraft 可读取的 PNG，转换前后解码像素一致；资源过滤编码固定为 UTF-8。

保留 rc.7 全部玩法源码、测试和游戏资源，包括逐波楼梯状态保持、猪灵装备、副本怪物无掉落/无经验、建筑中心空间音乐，以及恢复的物品、附魔和懦弱效果。
