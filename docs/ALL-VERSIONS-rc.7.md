# 劫后余生 0.0.4-rc.7：逐波变形时保留楼梯方向

适用于 Forge 1.20.1，以及 NeoForge 1.21.1、1.21.2、26.1.1、26.1.2、26.2、26.3。

## 原因和修复

原来的变形处理器会把未被选中的方块的当前世界状态交回结构模板。模板放置时再应用一次建筑旋转，导致楼梯即使不换材质，也可能每波转一次方向。真正替换为下界楼梯时，模板自身的朝向、上下半部等状态也可能覆盖现场状态。

- 未被选中变形的方块直接跳过放置，不再重复旋转，也不重写其方块实体数据。
- 楼梯替换为下界楼梯时保留当前世界中的朝向、上下半部、拐角形状和含水状态；先转换回模板坐标下的状态，再由原版放置流程旋转，避免重复旋转。
- 黑曜石和已开启的传送门直接跳过，保持门框及传送门轴向。
- 每波开始变形、每个候选方块约 10% 的变形概率和下界材质模板保持原有规则；沿用原版邻居形状更新。

更新会停止后续波次造成的转向。已经被旧版转歪的楼梯不会被自动识别并复原，以免强制覆盖玩家调整后的建筑。

## 回归验证

新增三个 GameTest 使用 Minecraft 的实际结构模板放置流程，调用与真实副本相同的变形设置，检查实际放置后的方块状态。

1. 未选中变形的楼梯：四种建筑旋转 × 四种楼梯朝向 × 上下半部，每组连续 11 轮；额外检查门框及两种传送门轴向不变。
2. 已选中变形的楼梯：四种建筑旋转 × 四种朝向 × 上下半部 × 五种楼梯形状 × 两种含水状态，每组连续 11 轮，在两种下界楼梯材质之间替换并验证状态。此项使用模板的已知形状选项，单独验证完整状态保存。
3. 正常邻居更新：实际摆出直梯、内外左右拐角，在四种建筑旋转、四种楼梯朝向、上下半部组合下连续 11 轮交替选择和跳过变形，验证原版邻居更新后仍保持几何形状。

三项合计 512 组楼梯配置，每组 11 轮，另有 12 组门框／传送门保护检查。26.1.2 的修复前代码在这三项中均失败：未选中楼梯在 90° 旋转下转向，选中楼梯的上下半部被覆盖；修复后重新验证。

各版本完整测试数量、可选 KubeJS 环境结果见 [验证记录](VALIDATION.md)，产物 SHA-256 见 [rc.7 清单](rc.7-manifest.json)。已有物品、附魔、懦弱效果、猪灵装备、掉落、音乐和副本生命周期测试也包含在回归套件中。

复现命令（进入相应工程，使用 README 中指定的 Java 版本）：

```powershell
.\gradlew.bat runData
.\gradlew.bat runGameTestServer clientAudioCheck build
```

自动验证覆盖实际服务端方块状态及模板旋转，但本次没有进行图形客户端逐波画面验收或真人多人实玩。

## 安装

按 Minecraft 版本选择对应 JAR 替换 rc.6 或更早的版本。1.20.1 为 Forge，其余六个目标为 NeoForge；联机客户端和服务端同步更新。此前恢复的物品、附魔、交易和效果，以及 rc.6 的装备、无掉落和空间音乐修复均保留。
