# 劫后余生 rc.16：可无限投掷的下界核心

适用于 Forge 1.20.1，以及 NeoForge 1.21.1、1.21.2、26.1.1、26.1.2、26.2、26.3。

## 使用方法

在主世界手持下界核心，右键抛出。远处会寻找附近符合实际世界生成规则的城市，接近后会指向附近存活的遗物商人。跟随飞行方向、捡回核心，再次投掷即可继续前进。寻找城市时会显示提示，请保持手持；换手中物品、移动超过 32 格、死亡、离线或切换维度会取消等待中的投掷。

每次生存模式投掷取出一颗，约三秒后完整返还一颗；撞到实体方块会提前落下。没有随机碎裂，没有耐久损耗，可以反复使用。自定义名称和物品数据会保留，飞行状态随实体存档保存。落地的引导核心不会因五分钟超时消失，并免受普通伤害。创造模式保留手中数量，展示飞行但不额外掉落，以免复制兑换货币。

仍使用原来的下界核心物品 ID、贴图和交易方式；它仍可用于遗物商人的奖励兑换。右键不会点燃方块或激活副本。

## 城市与商人

新生成的城市会在中心区固定安排一名遗物商人，其他随机村民仍照常生成。商人使用已注册的职业、贴图与交易，带有职业经验以避免失业。

旧城市不会自动增加商人，也不会复活已死亡的商人。核心接近旧城市后若找不到存活的商人，会继续搜索其他城市。附近已经加载的商人按实际位置定位；远处首先引导到城市，并不能预先保证某位尚未加载的旧商人仍然存活。

城市搜索使用当前种子、结构间距、生物群系、地形和其他结构避让规则，按由近到远的放置区域寻找合适候选，不保证数学上绝对最近。默认搜索最多 12 圈放置区域（城市间距为 32 区块时，约六千格量级），找不到会提示重试且不会扣除核心。

搜索在后台执行纯世界生成预测，不强行生成城市或远处区块。服务器主线程负责已加载实体查询、结果检查、物品扣除和飞行实体生成，过期或取消的结果不会再取走物品。关闭结构生成的世界仍可寻找附近已存在的遗物商人。

## 验证范围

新增下界核心专项 GameTest：连续 128 次投掷与数量守恒、途中保存重载、真实右键和服务器飞行、缺少目标与创造模式、撞墙和 6100 个掉落物 tick、后台搜索和取消操作。自然城市生成测试同时要求首次生成就有且仅有一名固定商人，保留原有碰撞、交易和职业保持检查。

同时回归城市地形、树叶、水体与建筑保护、附魔书、食物、奖励兑换、副本、楼梯变形和音频检查；检查生产 JAR 的注册类、Mixin、原贴图、中文提示和版本元数据。

这些是自动化服务器和资源验证，不代表已经完成客户端画面与手感的人工游玩测试。此前已经生成或破坏的城市地形不会被本版本自动重建。
