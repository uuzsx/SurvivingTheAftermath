# 劫后余生 0.0.4-rc.6：全版本同步修复

这次把原先仅在 26.1.2 生效的装备、掉落和音乐修复同步到其余六个维护版本，并保留 rc.5 恢复的全部物品、附魔、交易和懦弱效果。26.1.2 也统一升级版本号并重新验证。

## 修复内容

- 波次怪物先执行出生初始化，再应用配置装备；首波普通猪灵作为成年战斗单位持有金剑或弩，猪灵蛮兵恢复初始武器。后续配置的武器、护甲直接装入对应装备槽，配置优先于随机初始装备。
- 副本怪物不掉落物品、装备和经验，也不会捡走通关奖励。无掉落标记随实体保存，副本结束清理战斗标记后仍生效；仍带有旧战斗标记的怪物在加载时补上此规则。
- 岩浆怪分裂产生的小怪继承所属副本和无掉落规则；附近的野生岩浆怪不再被误加入副本。自然生物和玩家背包掉落保留。
- 胜利音乐以建筑包围盒中心为声源，在 48 格范围内随距离衰减。使用单声道完整音源和游戏“唱片机／音符盒”音量分类。
- 通关时开始播放音乐并发奖；发奖结束关门后，音乐可自然播完。**成功重新激活会停止上一首音乐，开始新挑战**；激活失败不会停歌。
- 最后一名玩家离开播放范围后结束本次播放，之后回来不会继续播放。范围内始终有人时，新进入的玩家从当前歌曲进度加入。

这次没有修改波次数、奖励内容、难度配置或钻石打火石配方。配方仍为 1 个燧石＋1 个钻石。

## 验证内容与复现

七个工程分别执行资源生成、专用游戏测试服务端、实际客户端 Ogg 解码检查和构建。完整结果与每个 JAR 的 SHA-256 见 [验证记录](VALIDATION.md) 和 [产物清单](rc.6-manifest.json)。

新增的六项回归测试在每个目标版本中运行，覆盖默认 11 波反复生成的猪灵装备、配置装备覆盖、实际死亡时的物品和经验拦截、自然生物和玩家掉落保护、实际岩浆怪分裂、建筑中心声源、两名玩家分别离开及返回，以及音乐数据包往返。原副本生命周期测试同时检查通关发奖、拒绝激活不断歌、重开停歌；rc.5 的物品、附魔、翻译与交易测试一起运行。

音频检查使用各版本 Minecraft 实际使用的解码器，验证单声道及 0、1、17、2000、5391、6000 tick 六个播放偏移与结尾场景。1.20.1 使用 OggAudioStream，其余目标使用 JOrbisAudioStream。

在对应工程、使用 README 表中的 Java 版本执行：

```powershell
.\gradlew.bat runData
.\gradlew.bat runGameTestServer clientAudioCheck build
```

1.20.1、1.21.1、26.1.2 另有 KubeJS 桥接，可用 `-PwithKubeJS runGameTestServer` 验证；基础玩法不依赖 KubeJS。GitHub Actions 配置也加入了游戏测试和音频检查。

这些自动验证没有替代图形客户端实玩、真人联机、实际扬声器听感和整合包兼容性验收。

## 安装

按 Minecraft 版本和加载器选择一个 JAR 替换旧版。1.20.1 使用 Forge，其余六个版本使用 NeoForge；联机时客户端和服务端一起更新。

此前已掉在地上的物品不会被回收；旧怪物若早已失去副本标记，无法再可靠判断其来源，不会按距离猜测并禁掉野生怪物的掉落。
